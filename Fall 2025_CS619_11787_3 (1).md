Prototype Phase: Fake News Detection Using AI

Introduction 

The Prototype or Test Phase assignment is one of the most important activities of the final project. In this assignment, you will implement some functionalities related to the final project. The objective is to implement some of the requirements of the Fake News Detection system and provide a basic understanding of implementation.

In this Prototype phase, the focus is to create a Web App connected to a database that performs CRUD operations along with AI-based fake news detection features.

The following functionalities should be implemented in the test:

Users Registration/Profile Management: \- 

Secure Registration & Privacy Protection: Users register, admin verifies details, and users can view and update their profiles while maintaining strict privacy.

News Submission & Analysis: \- 

News Submission: 

Users submit news articles or headlines for analysis. \- AI Detection: The system analyzes submitted news using a basic AI/ML model and returns results as “Real” or “Fake” with a confidence score. \- History Management: Users can view the history of previously analyzed articles.

Admin Panel Features: \-

 Admin manages user accounts (add, update, delete). \- Admin uploads and updates training datasets for the AI model. \- Admin retrains the AI model when new data is added. \- Admin can view system performance metrics (accuracy, precision, recall, F1-score) and generate usage reports. \- Admin ensures data security and user privacy.
